This is a Kotlin Multiplatform project targeting Android and Desktop (JVM) with a shared POS network printing module.

## Modules

- `:composeApp` - Compose Multiplatform UI for Android + Desktop.
- `:shared:core` - shared core base module.
- `:shared:domain` - shared domain base module.
- `:shared:data` - shared data base module.
- `:shared:printing` - production-ready ESC/POS network printing module.

## Phase 1 Printing (Network ESC/POS)

`shared:printing` provides:
- Receipt domain models using integer money (`Long` cents).
- ESC/POS byte builder in shared common code.
- `PrinterService` abstraction.
- Android and Desktop implementations using raw TCP sockets.
- Koin DI bindings for platform printer services.

## Typical Network Printer Setup

1. Connect thermal printer to same LAN as Android/Desktop device.
2. Find printer IP from printer self-test page or router DHCP table.
3. Use RAW TCP port `9100` (most ESC/POS printers default to this).
4. In app UI, enter `host`, `port`, and paper width (`32`, `42`, or `48`).
5. Press **Print Test Receipt**.

> Note: UTF-8 bytes are generated by default. Some printers require explicit ESC/POS code page settings for Arabic/CP1256 output.

## Run Android

```bash
./gradlew :composeApp:installDebug
```

Or from Android Studio, run `composeApp` on a device/emulator.

## Run Desktop

```bash
./gradlew :composeApp:run
```

## Run shared printing tests

```bash
./gradlew :shared:printing:allTests
```
